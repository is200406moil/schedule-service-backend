# План обновления интерфейса

Обновлено 1 октября 2026 после сравнения с ЛКС и «Пульсом» МИРЭА.
Предыдущий перенос на React подтвердил работоспособность, но не удобство:
профиль открывался формой, связанные панели выглядели отдельными карточками,
а мобильная версия повторяла десктопную.

## Направление

Студент открывает сервис, чтобы быстро увидеть пары и сроки, а не заполнять
анкету. Профиль по умолчанию показывает сохранённые данные. Редактирование
открывается отдельным действием. Аккаунт и выход доступны из меню справа сверху.

Один логотип, шрифт Golos Text и одинаковые внешние отступы во всех разделах.
Белые рабочие поверхности, спокойный серо-синий фон, navy для навигации,
синий для действий. Жёлтый и зелёный — небольшие смысловые акценты.
Заголовки 28–32 px, обычный текст 14–16 px; никаких рекламных hero-блоков.
Связанные области объединяются в одну поверхность. Рамка используется только
там, где обозначает границу действия или группы данных.

Не растягиваем каждую карточку искусственно до высоты соседней. Вместо этого
сначала выбираем композицию: общий контейнер для связанных областей или
ровная сетка действительно равноправных блоков.

## Этапы

1. **Оболочка и профиль — готовы к просмотру, без коммита.** Общий логотип, верхнее меню аккаунта,
   просмотр профиля без полей ввода, отдельное редактирование. Мобильное окно
   задачи выезжает снизу; свайп за ручку не мешает прокрутке и не теряет черновик.
2. **Календарь.** Один рабочий блок: компактный месяц и занятия выбранного дня.
   Карточки пар содержат время, предмет, аудиторию и преподавателя. Перерывы
   вычисляются из времени занятий, а не задаются вручную. Проверяем дни с
   10- и 30-минутными перерывами, без пар и с недоступным расписанием.
3. **Обзор и задачи.** Вместо большого приветственного баннера — текущий день,
   расписание и ближайшие сроки. Связанные панели выровнены по общей сетке,
   тексты короткие, действия не дублируются без необходимости.
4. **Вход и регистрация.** Те же логотип, поля и типографика. Чётко различимые
   ошибки, обязательные поля, автозаполнение и показ пароля. Без декоративных
   слоганов и растянутых пустых областей.
5. **Структура и интеграция.** Проверить общие компоненты, повторяющуюся загрузку
   данных, границы API и UI. По завершении переноса убрать временные сравнения
   версий; старые маршруты не удалять до проверки новых сценариев.

Уже выявлены три конкретных долга, а не просто «слишком длинные файлы»:
повторяющееся управление задачами/ошибками в четырёх разделах; отсутствие дат
действия семестра и версии расписания в контракте API; две параллельные версии
интерфейса. Границы семестра особенно важны: недельный шаблон нельзя безусловно
показывать на каникулы и произвольные прошлые годы.

## Что считается готовым этапом

- Видно результат в браузере на настоящем расписании, а не только на ошибке загрузки.
- Проверены обычный десктоп, 375 и 320 px, landscape и увеличение текста.
- Редактирование и выход не навязаны на экране просмотра.
- С клавиатуры доступны меню, формы, отмена и закрытие.
- Свайп имеет альтернативу кнопкой; сохранение и несохранённый черновик защищены.
- Нет горизонтального переполнения и скрытых за фиксированными панелями действий.
- Сборка, клиентские и серверные тесты проходят. Это технический критерий,
  а не доказательство хорошего дизайна.
- Пользователь посмотрел снимки и одобрил этап. Только после этого коммит.

## Среда проверки

Интерфейс: `http://127.0.0.1:8765`, отдельная локальная SQLite-база и тестовый
аккаунт. Сервис расписания: `http://localhost:5000`, scoped контейнеры
`schedule-api` и `schedule-db`. Существующие данные пользователя не подменяем.
Для проверки перерывов группы ИКБО-14-23 используем 2 октября 2026:
09:00–10:30, 10:40–12:10, 12:40–14:10, 14:20–15:50.

## Проверка первого этапа

В браузере проверены просмотр профиля, переход из меню в редактирование,
сохранение с нормализацией имени, отмена и возврат фокуса. Escape закрывает
меню и возвращает фокус на аватар. Поля не появляются на странице просмотра.

Проверены 1280×900, 375×812, 320×740 и 812×375. На коротком landscape форма
тоже остаётся нижней панелью: кнопки не прокручиваются вместе с полями.
Длинный жест закрывает пустую форму, короткий возвращает её на место.
При заполненном названии жест открывает подтверждение; «Продолжить»
сохраняет черновик. Горизонтального переполнения на 320 px нет.

Сборка, 85 клиентских и 60 серверных тестов проходят. Расписание группы
загрузилось в браузере с четырьмя настоящими парами на 2 октября. Макет
календаря при этом ещё прежний: перерывы и общий контейнер — следующий этап.
Увеличение системного текста и экранную клавиатуру на физическом телефоне
пока не проверяли. Визуальное одобрение пользователя ещё не получено.
